# 🔍 افزونه Fyndo

**Fyndo** یک افزونه‌ی جستجوی زنده برای وردپرس و ووکامرس است که با استفاده از **Ajax** نتایج محصولات را بدون نیاز به رفرش صفحه نمایش می‌دهد.

---

## ⚙️ ویژگی‌ها

- جستجوی زنده (Real-time Search) با Ajax  
- نمایش نتایج محصولات هنگام تایپ کاربر  
- سازگار با **WooCommerce**  
- طراحی سبک و قابل سفارشی‌سازی  
- نصب و فعال‌سازی آسان  

---

## 🚀 نحوه استفاده

 1-افزونه را نصب و فعال کنید.
 
 2-این شورت‌کد را در برگه یا ابزارک دلخواه خود قرار دهید: [fyndo_ajax_search]
 
 3-جستجوی زنده محصولات آماده است! 🔥
